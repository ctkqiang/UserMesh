已完成的提交
============

1. 重组: 将所有文档文件移到 docs/ 目录
   - 创建 docs/ 目录结构
   - 组织文档分类存放
   - 创建 docs/guides/, docs/api/, docs/examples/, docs/architecture/, docs/contributing/ 子目录

2. docs: 更新主 README 文档链接
   - 所有文档链接指向 docs/ 目录
   - 简化文档导航说明
   - 移除已过时的文档链接

3. feat(core): 核心 SDK 和配置验证
   - UserMeshAnalyticsSdkClient: 主 SDK 类 (~900 行)
   - UserMeshConfigurationValidator: 配置验证

4. feat(encryption): 加密服务实现 AES-256-GCM
   - UserMeshDataEncryptionService: 完整加密/解密
   - AES-256-GCM 认证加密

5. feat(validation): 事件验证引擎
   - UserMeshEventValidator: 完整事件验证
   - 7 个核心验证规则 + 自定义规则支持

6. feat(state): Zustand 状态管理存储
   - UserMeshEventQueueStore: 事件队列状态
   - UserMeshUserProfileStore: 用户资料状态

7. feat(storage): 离线队列存储和持久化
   - UserMeshOfflineEventQueueStorage: 队列管理
   - UserMeshLocalStorageAdapter: localStorage 实现

8. feat(utils): 实用工具类
   - UserMeshIdentifierGenerator: 唯一标识符生成

9. feat(exports): 导出所有公共 API
   - 导出核心 SDK 类
   - 导出所有类型定义和状态存储

功能特性
========

核心功能:
- 事件追踪 (自动上下文丰富)
- 用户识别和特征管理
- 会话追踪和分组
- 设备/浏览器检测
- 页面浏览追踪
- 错误事件追踪

多平台支持:
- Google Analytics 4
- PostHog
- Mixpanel
- Microsoft Clarity
- 自定义 HTTP 端点

离线和恢复能力:
- 自动离线队列
- localStorage 持久化
- 指数退避重试
- 配额管理
- 自动缓存清理

安全和隐私:
- AES-256-GCM 加密
- 隐私控制 (选择退出/进入)
- PII 删除支持
- GDPR 合规性
- 不跟踪 (Do Not Track) 支持

开发者友好:
- 类型安全 TypeScript
- 长的、可读的变量名
- 完整的文档
- 清晰的错误信息
- Zustand 状态管理
- 配置验证
