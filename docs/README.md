## 快速导航

### 快速开始 (15分钟)
1. 阅读项目根目录 `README.md`
2. 查看 `examples/EXAMPLES.md` 中的示例
3. 开始集成 UserMesh SDK

### 学习概念 (1小时)
1. 阅读 `guides/DEVELOPER_GUIDE.md`
2. 学习核心概念和使用方法
3. 参考 `examples/EXAMPLES.md` 中的代码

### API 文档
查看 `api/API_REFERENCE.md` 了解所有 API 方法、类型定义和配置选项。

### 贡献代码
请先阅读 `contributing/CONTRIBUTING.md` 了解开发规范和贡献流程。

### 架构与集成
- `architecture/ARCHITECTURE.md` - 系统设计
- `architecture/INTEGRATIONS.md` - 平台集成详情

## 文档说明

### guides/DEVELOPER_GUIDE.md
- 完整的开发者指南 (1000+ 行)
- 涵盖所有概念、使用方法、配置、示例
- 包含故障排除指南
- 每个功能都解释 WHAT、WHY、WHEN、HOW

### api/API_REFERENCE.md
- 完整的 API 文档 (900+ 行)
- 所有方法、类型、配置选项
- 每个 API 都有详细的参数说明和示例

### examples/EXAMPLES.md
- 5 个实际应用领域的完整示例
- 电子商务、金融交易、社交媒体、SaaS、React 集成
- 每个示例都包含完整的事件追踪代码

### architecture/ARCHITECTURE.md
- 系统设计和架构说明
- 各个模块的职责和关系

### architecture/INTEGRATIONS.md
- Google Analytics 4、PostHog、Mixpanel 等平台的集成详情
- 如何获取平台凭证

### contributing/CONTRIBUTING.md
- 开发环境设置
- 代码质量标准
- 测试要求
- 贡献工作流程
