## ❓ FAQ / 常见问题

**Q: Is UserMesh open source?**  
A: UserMesh is available open source on [GitCode](https://gitcode.com/ctkqiang_sr/UserMesh.git). It's free to use and modify.

**Q: 我能在商业项目中使用 UserMesh 吗？**  
A: 是的，UserMesh 采用 MIT 许可证，完全可以在商业项目中使用。

**Q: Which analytics platforms are supported?**  
A: Google Analytics 4, PostHog, Mixpanel, Microsoft Clarity, and any custom HTTP endpoint.

**Q: UserMesh 支持离线模式吗？**  
A: 是的，所有事件都会自动持久化到本地存储，网络恢复后自动上传。

**Q: Can I use multiple analytics platforms simultaneously?**  
A: Yes! That's the main feature - track once, send to all enabled platforms.

**Q: 是否支持服务器端集成？**  
A: 当前支持网页（浏览器）集成。服务器端支持正在规划中。
